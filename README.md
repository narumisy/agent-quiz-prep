# Agent 智能体竞赛备考手册

针对初赛笔试的专项备考资料库。覆盖全部考纲内容，配套答题策略与 11 天备考计划。

## 考试概况

- 时间：8 月 21 日，90 分钟笔试（柳州、青岛、重庆、上海四地集中）
- 形式：单选 70 题×1 分 + 多选 10 题×2 分 + 判断 20 题×0.5 分 = 100 分
- 晋级：笔试成绩前 30 名进入决赛

## 资料结构

| 文件 | 内容 |
|------|------|
| `Agent智能体竞赛备考手册.md` | 全量考纲知识点手册（四大板块 + 易错题速记 + 11 天备考计划） |
| `题库.md` | 出题自测题库，记录已出题目、答案解析与作答统计 |

## 考纲覆盖范围

1. **基础知识**：计算机操作系统 / 软件 / 硬件 / 安全 / 网络 / 移动互联网 / 云计算与大数据 / 人工智能基础 / 图像处理 / Python 基础 / 相关法律法规
2. **系统设计**：Agent 概念 / 架构模型 / 多 Agent 协作 / 系统组件与关键技术 / 工作流编排 / 系统评估维度 / 工程化与治理
3. **提示词工程**：基本概念 / 系统与用户提示词 / 思维链 / 核心要素 / 提示词框架 / 负向约束与安全性
4. **功能模块开发与应用**：开发平台 / 开发框架 / 向量数据库 / 工具调用原理 / RAG 技术 / API 与数据集成 / 长短期记忆机制

## 使用建议

1. 第 1 遍通读手册，按板块建立知识框架
2. 用「附录 A：高频易错判断题」自测并记录错题
3. 通过对话发起出题自测（每次一题，答后自动批改并解析），错题记录到 `题库.md`
4. 参考「附录 B：11 天备考计划」按天推进
5. 考前回顾「速记卡」，重点记忆 Agent 循环、ReAct、RAG 流程、向量库指标
