## 提示词工程 AI 评分工具（任务 B 备考）

针对任务 B「提示词工程」交付物（System Prompt）的自动评分工具：

- **8 维加权评分模型**：角色定位 / 任务明确性 / 指令结构化 / 上下文完整 / 约束明确性 / 输出格式规范 / 边界异常 / 示例稳健（权重合计 100）
- **AI 评审**：调用 `deepseek-v4-flash`（token.sensenova.cn 兼容接口），逐维打分 + 中文评语 + 优点 + 改进建议，自动重试，输出程序可直接解析的 JSON
- **深度题库（9 题·按题评分）**：`prompt_questions.py` 内置题目库，涵盖角色扮演 + CoT + Few-shot + JSON 结构化、RAG 防幻觉、回答一致性、情感分类、工单路由、提示注入防御、思维链解题、多语言文案等考点
  - 每道题独立题面、难度、考察要点与详细解析
  - 评分时把该题**考察要点**注入评审模型，逐条输出「已覆盖 / 未覆盖」核查结果，并附带题目解析
  - 前端下拉切换题目，自动载入题面与参考示例，评分随题目切换

```bash
# 启动评分服务（静态页 + /api/score 接口，仅标准库）
python3 scorer_server.py --port 8000
```

浏览器打开后：粘贴你的 System Prompt → 点击「开始 AI 评分」→ 查看总分、等级与逐维点评。

## 答题网页功能

- **一次一题**：单选 / 多选 / 判断三种题型，提交后在选项区域直接展示判定、正确答案与解析
- **智能出题**：题目随机排序，优先出答题次数少的题；每题选项顺序随机打乱，答案索引同步重映射
- **数据持久化**：答题结果（每题答对/答错次数）存入浏览器 localStorage，累计正确率实时统计
- **错题重练**：答对少于答错的题自动进入错题本并带角标，一键切换模式；攻克后自动移除
- **固定布局**：答题卡牌置顶，页面高度稳定，答题过程无需滚动

本地启动预览：`python3 -m http.server 8000`，浏览器访问 `http://localhost:8000`

## 使用建议

1. 第 1 遍通读手册，按板块建立知识框架
2. 用「附录 A：高频易错判断题」自测并记录错题
3. 用答题网页反复刷题，利用"优先出答题次数少的题"覆盖盲区，"错题重练"攻克薄弱点
4. 参考「附录 B：11 天备考计划」按天推进
5. 考前回顾「速记卡」，重点记忆 Agent 循环、ReAct、RAG 流程、向量库指标
