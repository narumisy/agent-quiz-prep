# Agent 智能体竞赛 · 决赛备赛包

> 决赛形式：现场实操 120 分钟，完成任务书内容。

## 任务与分值一览

| 任务 | 分值 | 内容 | 工具 | 交付物 | 评分维度 |
|------|------|------|------|--------|----------|
| A 系统设计 | 30 | 制造/质量/营销/售后中选一处场景做 AI 化改造 | 百炼平台组件 | Agent 成品 + 说明文档（文字+截图） | 文档清晰度、功能完整度、视觉效果 |
| B 提示词工程 | 30 | 基于知识文档实现知识问答 | 百炼平台组件、LangChain 组件 | 完整提示词（Markdown） | 提示词完整度、准确度、清晰度 |
| C 功能模块开发 | 40 | 开发一款可运行的 Agent | LangChain 组件、基础 Python | 核心代码 + 测试运行截图 | 功能完整性、代码逻辑、集成度、多模态、异常机制 |

## 120 分钟时间分配建议

| 时间段 | 时长 | 做任务 | 说明 |
|--------|------|--------|------|
| 0-5 分钟 | 5 | 全局浏览任务书 | 明确三题要求、工具环境、上传路径 |
| 5-40 分钟 | 35 | 任务 C（40 分） | 最高分值且需要跑代码，最先做，把代码跑通、截图 |
| 40-75 分钟 | 35 | 任务 B（30 分） | 纯提示词交付，套模板 + 适配题目文档 |
| 75-110 分钟 | 35 | 任务 A（30 分） | 套场景模板，创建 Agent，逐环节截图 |
| 110-120 分钟 | 10 | 检查交付 | 三份交付物完整、截图清晰、命名规范、可复现 |

> 原则：先做"要跑起来"的 C，再做"纯文案"的 B，最后做"要创建组件+截图"的 A。

## 使用前提

- 任务 A：阿里云**百炼平台**账号，熟悉「应用/Agent 创建 → 智能体编排 → 插件/知识库/工作流」流程。
- 任务 B：核心是提示词模板，不依赖账号，可完全提前准备。
- 任务 C：本备赛包已提供**可直接运行**的脚手架，支持两种模式：
  - **真实模式**：填写 `.env` 中的 `USER_LLM_API_KEY` 等变量，调用真实大模型（百炼/DeepSeek/OpenAI 均可）。
  - **模拟模式**：不填 Key 时自动降级，用检索到的知识片段拼接生成回答，无网无 Key 也能跑通流程并截图。
