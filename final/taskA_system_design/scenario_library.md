# 任务 A · 备选场景库

> 从制造、质量、营销、售后四领域中任选一处场景进行 AI 化改造。
> 建议赛前锁定 **1 个主场景 + 1 个备选场景**，现场直接套用 `agent_design_doc_template.md`。

## 选型建议（优先级）

| 优先级 | 场景 | 理由 |
|--------|------|------|
| 1 | 售后 · 智能客服知识问答 Agent | 与任务 B、C 高度同构，知识库/提示词可三题复用，最容易做出"完整度" |
| 2 | 制造 · 设备故障智能诊断与预警 | 场景具象、痛点清晰、架构容易画出 |
| 3 | 质量 · 质量数据分析与缺陷归因 | 可用表格/图表增强视觉效果 |
| 4 | 营销 · 智能营销文案生成 | 效果直观，但功能完整度维度略吃亏 |

---

## 领域一：制造（Manufacturing）

### 1.1 设备预测性维护 / 故障智能诊断
- **痛点**：设备突发停机导致产线中断；维修依赖老师傅经验，知识难沉淀。
- **AI 化改造**：接入设备实时状态数据（振动/温度/电流）做异常检测；当出现异常或报错时，Agent 依据设备知识库给出故障原因排查步骤与维修建议。
- **Agent 功能**：
  - 设备状态数据解读与异常报警
  - 故障码查询与原因定位
  - 基于维修知识库的排查步骤建议
  - 维修工单自动生成
- **百炼组件**：智能体应用编排、知识库（上传设备手册）、工作流（数据接入→判断→输出工单）、工具插件（工单系统 API）。

### 1.2 智能生产排产助手
- **痛点**：人工排产耗时长、订单交期预估不准。
- **Agent 功能**：读取订单与产能数据，输出排产建议、交期预估、瓶颈预警。
- **百炼组件**：知识库（工艺参数）、工作流（数据查询→排产计算→建议输出）、插件（ERP/APS 数据 API）。

### 1.3 产线智能质检（视觉）辅助
- **痛点**：人工目检效率低、漏检率高。
- **Agent 功能**：对接图像采集，识别缺陷类型与等级，输出质检报告与处置建议。
- **百炼组件**：插件（视觉质检 API/模型）、工作流（图片输入→识别→报告）、知识库（缺陷标准库）。

## 领域二：质量（Quality）

### 2.1 质量数据分析与缺陷归因
- **痛点**：质量报表靠人工拉数分析，缺陷根因定位慢。
- **Agent 功能**：输入质量问题描述/批次号，自动检索质检记录、归类缺陷、给出根因假设与改进建议。
- **百炼组件**：知识库（历史质检报告、8D 报告）、工作流（检索→归因→建议）、插件（MES/QMS 数据 API）。

### 2.2 质量体系文件问答（SOP 助手）
- **痛点**：质量文件多、条款分散，一线员工检索慢。
- **Agent 功能**：基于质量体系文件（SOP/作业指导书/标准）做问答，引用条款出处。
- **百炼组件**：知识库（全文检索）、智能体编排（带引用规则）。
- **优势**：与任务 B/C 同构，实现成本最低。

### 2.3 不合格品处置流程助手
- **Agent 功能**：判定不合格品处置路径（返工/让步接收/报废），生成处置单与审批流。
- **百炼组件**：工作流（判定规则→处置路径）、知识库（判定标准）、插件（质量系统 API）。

## 领域三：营销（Marketing）

### 3.1 智能营销文案生成助手
- **痛点**：新品上市需要多平台多版本文案，产出慢、风格不一致。
- **Agent 功能**：输入产品信息/卖点/目标人群，生成公众号、短视频脚本、电商详情页等文案，并统一品牌语气。
- **百炼组件**：智能体编排（角色+风格约束）、知识库（品牌手册/历史爆款文案）、工作流（输入→拆解→多版本输出）。
- **视觉亮点**：截图对比"输入卖点 → 输出多平台文案"，效果直观。

### 3.2 客户画像与精准营销分析
- **Agent 功能**：基于客户数据输出画像摘要、分层建议、活动投放建议。
- **百炼组件**：工作流（数据查询→画像分析→建议）、知识库（活动规则库）、插件（CRM 数据 API）。

### 3.3 社媒舆情监控助手
- **Agent 功能**：汇总评论/舆情，识别情绪倾向，输出热点总结与回复建议。
- **百炼组件**：工作流（数据采集→情感分析→报告）、插件（舆情 API）。

## 领域四：售后（After-sales）

### 4.1 智能客服知识问答 Agent（首选推荐）
- **痛点**：客服人力成本高、响应慢、FAQ 覆盖不全；多产品线知识分散。
- **AI 化改造**：把产品手册/FAQ/常见故障处理流程接入知识库，Agent 自动回答用户咨询，复杂问题转人工。
- **Agent 功能**：
  - 产品咨询、使用指导自动问答（带引用出处）
  - 常见故障排查步骤引导
  - 复杂问题识别并转人工工单
  - 多轮对话上下文保持
- **百炼组件**：
  - 智能体应用（角色设定 + 系统提示词）
  - 知识库（上传产品手册、FAQ、故障处理文档，配置分段与检索策略）
  - 工作流（意图识别 → 知识库检索 → 答案生成 → 无答案转人工）
  - 工具插件（工单系统接口、转人工 API）
- **优势**：与任务 B（知识问答提示词）、任务 C（RAG Agent）三题同构，一套素材三处得分。

### 4.2 智能工单分诊助手
- **痛点**：工单人工分拣耗时、分配不准。
- **Agent 功能**：根据工单描述自动分类、定级、分配责任人，并给出处理建议。
- **百炼组件**：工作流（工单解析→分类→定级→分配）、知识库（服务目录/历史工单）、插件（工单系统 API）。

### 4.3 产品故障远程诊断 Agent
- **Agent 功能**：用户描述故障现象（文字/图片），Agent 引导排查，给出自助修复步骤或上门/返修建议。
- **百炼组件**：知识库（故障排查手册）、工作流（现象→诊断树→结论）、多模态插件（图片识别故障）。

## 决赛现场速用 Checklist

1. 从场景库选 **1 主 1 备**（建议「4.1 智能客服」+「1.1 设备诊断」）。
2. 打开 `agent_design_doc_template.md`，按占位符填场景内容。
3. 在百炼平台创建 Agent：设置角色提示词 → 挂知识库 → 配工作流 → 配插件 → 试跑。
4. 每完成一个配置环节，**立即截图**（标题命名如 `01-创建应用.png`），贴进文档。
5. 试跑 3 类问题（正常问答 / 无知识兜底 / 多轮追问），分别截图，证明功能完整。
