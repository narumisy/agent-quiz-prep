# 常见问题 FAQ

## 1. 设备如何恢复出厂设置？

长按设备侧面 RESET 按键 5 秒，指示灯开始闪烁后松开，设备将恢复出厂设置并自动重启。恢复后需重新配置网络与采集参数。

## 2. 如何升级设备固件？

登录管理平台，在「设备管理 → 固件升级」页面选择目标版本，系统会自动推送并升级。升级过程中请勿断电，等待设备指示灯恢复绿色常亮。

## 3. 设备离线如何处理？

先检查设备电源与网络指示灯，确认供电与网络正常；再检查管理平台中设备的通信配置是否被修改；若仍未恢复，尝试重启设备。

## 4. 采集数据上传到哪个平台？

数据默认上传至企业指定的工业物联网平台，也可通过平台开放 API 对接第三方系统。

## 5. 一个管理账号最多可绑定多少台设备？

普通账号最多 100 台，企业版账号最多 1000 台，超出部分需联系商务开通扩容。

## 6. 设备的质保期是多久？

本产品自购买之日起提供 24 个月质保，具体条款以《产品说明书》第四章为准。
