# XX 智能设备产品说明书

## 一、产品概述

XX 智能设备是面向中小企业的多功能工业控制终端，支持数据采集、远程监控与故障上报。设备内置 4G/5G 通信模块与边缘计算单元，适用于产线设备、仓储环境等场景。

## 二、主要技术参数

- 工作电压：DC 12V / 24V
- 工作温度：-20℃ ~ 60℃
- 通信方式：4G / 5G / 有线以太网
- 数据接口：RS485、RS232、以太网口、2 路模拟量输入
- 防护等级：IP65
- 功率：≤ 5W

## 三、安装说明

1. 将设备固定于导轨或壁挂安装位，确保通风散热。
2. 连接电源线，接线前务必确认电压与设备标注一致。
3. 接入网络：通过有线网口或插入 SIM 卡启用蜂窝通信。
4. 上电后观察指示灯，绿色常亮表示运行正常。

## 四、质保政策

本产品自购买之日起提供 24 个月质保。质保期内因产品自身质量原因导致的故障，由厂家免费维修或更换。人为损坏、进水、私自拆机不在质保范围内。

## 五、日常维护

- 每季度清理一次设备表面灰尘，检查接线是否松动。
- 定期查看固件版本，及时通过管理平台升级。
- 长期停用时断开电源，妥善存放于干燥环境。
