# 常见故障排查手册

## 错误码 E102：通信模块初始化失败

**现象**：设备上电后，通信指示灯持续红色闪烁，管理平台显示设备离线。

**排查步骤**：
1. 检查 SIM 卡是否插好、是否欠费停机。
2. 检查天线连接是否牢固。
3. 进入系统设置，确认通信模块开关处于开启状态。
4. 断电重启设备，观察通信指示灯是否恢复正常。
5. 若重启后仍报 E102，联系厂家售后更换通信模块。

## 错误码 E205：传感器信号异常

**现象**：数据采集数值长时间无变化或明显偏离正常范围。

**排查步骤**：
1. 检查传感器接线是否松动或接反。
2. 用万用表测量传感器供电电压是否在标准范围内。
3. 将传感器拆下单独测试，排除传感器自身故障。
4. 校准模拟量输入通道的量程设置。

## 错误码 E310：固件升级失败

**现象**：升级过程中断，设备反复重启。

**处理建议**：
1. 确认升级期间未断电。
2. 重新下载完整固件包后再尝试升级。
3. 若设备无法启动，使用 USB 恢复模式重新刷写固件。
4. 仍无法恢复时联系售后处理。

## 网络类故障：设备在线但数据延迟

**排查步骤**：
1. 检查现场网络带宽与信号强度。
2. 降低采集频率，避免数据积压。
3. 检查平台上数据推送的间隔配置。
4. 大流量场景建议升级企业版接入网关。
