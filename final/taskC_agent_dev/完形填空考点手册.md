### 第 6 块：本地 RAG（必考，参数最多）

```python
PDF_PATH = os.path.join(os.path.dirname(__file__), "EOAI-知识库-v6.pdf")
PERSIST_DIR = os.path.join(os.path.dirname(__file__), "chroma_db_eoai")

def load_pdf_documents(pdf_path):
    reader = PdfReader(pdf_path)
    for i, page in enumerate(reader.pages):
        text = page.extract_text() or ""
        text = unicodedata.normalize("NFKC", text)              # 兼容字符归一化
        docs.append(Document(page_content=text,
                             metadata={"page": i, "source": pdf_path}))

def build_knowledge_base(pdf_path, persist_directory, k=4):
    text_splitter = RecursiveCharacterTextSplitter(
        chunk_size=500,      # 每块字符上限
        chunk_overlap=100,   # 相邻块重叠量（必须小于 chunk_size）
    )
    vectorstore = Chroma.from_documents(
        documents=splits,
        embedding=embeddings,
        persist_directory=persist_directory,
    )
    return vectorstore.as_retriever(search_kwargs={"k": k})       # k=4 召回片段数
```

- **记忆三件套**：`chunk_size=500`、`chunk_overlap=100`、`k=4`。
- 分块原则：chunk_size 应不小于文档最长完整段落，否则会截断语义；overlap 用于保留上下文衔接。
- `get_or_build_retriever`：判断向量库文件 `chroma.sqlite3` 是否存在（在该 persist 目录下）→ 存在直接 `Chroma(persist_directory=..., embedding_function=embeddings)` 加载，否则新建。
- **更换向量模型后必须重建索引**。

- **函数名 → name；docstring → description；类型注解 → 参数 schema**。docstring 是给 LLM 看的，必须说清三件事：**来源**（查哪里的资料）、**范围**（适用什么问题）、**输入**（query 传什么）。
- `@tool` 之后的函数**必须注册进 tools 列表** create_agent 才能用。
- Tavily 参数：`max_results=5`（结果条数）、`search_depth="basic"`（检索深度）、`include_answer=False`（不额外生成摘要）。

## 四、易错点（丢分高发区）

1. **base_url 末尾是 `/v1`**，不要再拼 `/chat/completions`。
2. **「工具描述 docstring」是给 LLM 看的**，不是给人看的——描述决定模型何时调哪个工具，缺来源/范围/输入三要素，模型就乱调。
3. **`@tool` 函数必须同时出现在 `tools = [...]` 列表里**，否则模型看不见这个工具。
4. **三个工具边界别写混**：本地知识库=EOAI PDF 企业资料；Aily=内部制度/流程/业务问答；Tavily=外部公开行业案例/实时信息。
5. **chunk_overlap 要小于 chunk_size**；chunk_size 不能小于文档最长整段。
6. **更换 embedding 模型后要重建向量库**（删掉旧 chroma 目录重建），否则维度不匹配/检索失准。
7. **Bearer 大写**；`global_variable` 嵌套在 body 里。
8. debug=True 会刷屏；考试交演示用 `debug=False`。
9. **temp 相关**：`agent.invoke` 的 messages 结构是 `{"messages": [{"role": "user", "content": ...}]}`，role 用 `"user"`。
10. 报错先看控制台堆栈：**未调工具→查描述/注册/模型能力；调用报错→查凭证、ID、超时、权限；无相关片段→查 PDF、分块、向量配置；答案无依据→查工具返回与提示词**。

## 五、考场操作流程（照做）

1. 打开题目主 py，先整篇浏览：哪些空、哪些已预设。
2. 从**环境变量块**确认哪些值已给（不必改），把注意力集中在**参数值空位**。
3. 按顺序过：LLM 模型名 → Embedding → 切分参数 → k → 工具列表 → SYSTEM_PROMPT → create_agent(mode/l/tools/system_prompt/checkpointer) → thread_id。
4. 填完先自查一遍大表（第三节），再运行。
5. 运行报错 → 看堆栈 → 用「沿链路定位问题」表格逐段排查 → 修 → 重跑。
6. 用三类问题验证：**本地知识**（问 EOAI 文档概念）、**企业知识**（问 Aily 制度流程）、**外部信息**（行业案例/实时动态）。
7. 确认无 `raise RuntimeError("缺少环境变量…")` 之类拦截，最终**左下角提交**（提交后成绩老师评分，期间看不到）。
