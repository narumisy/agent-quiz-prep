# 决赛现场 120 分钟执行清单

> 目标：三份交付物全部高质量完成，留 10 分钟检查。

## 阶段一：开题（0-5 分钟）

- [ ] 通读任务书，确认三个任务要求、交付物提交方式（平台上传/本地导出）、时间节点
- [ ] 确认现场机器已安装环境（Python、pip、浏览器、百炼账号可用）
- [ ] 打开本项目 `final/` 目录，确认三套模板/代码都在

## 阶段二：任务 C · 功能模块开发（5-45 分钟，40 分）

1. **5-10 分钟**：把赛题知识文档放入 `taskC_agent_dev/知识目录/`（支持 txt/md/pdf/docx）
2. **10-15 分钟**：运行 `python app.py --demo` 确认链路跑通
3. **15-25 分钟**：针对性优化——若赛题是特定领域，调整 `DEFAULT_SYSTEM_PROMPT` 与知识文档
4. **25-40 分钟**：截图取证（共 4 张左右）：
   - `01-demo问答.png`：`--demo` 输出（正常问答 + 无知识兜底）
   - `02-多轮对话.png`：交互模式追问效果
   - `03-图片识别.png`：`/image` 多模态输出
   - `04-异常兜底.png`：演示错误处理（如提问空问题 / 知识库空）
5. **40-45 分钟**：整理核心代码交付物（源码文件 + 截图汇总 + 运行说明）

## 阶段三：任务 B · 提示词工程（45-80 分钟，30 分）

1. **45-55 分钟**：打开 `taskB_prompt_engineering/knowledge_qa_prompt_template.md`
2. **55-70 分钟**：把赛题知识文档主题替换进模板【】占位，补齐示例与边界规则
3. **70-80 分钟**：用题目环境自测一遍（百炼/LangChain 组件跑通），校正引用格式

## 阶段四：任务 A · 系统设计（80-115 分钟，30 分）

1. **80-85 分钟**：选定场景（优先「智能客服」或与 B/C 同主题场景），打开模板
2. **85-100 分钟**：在百炼平台创建 Agent——角色提示词 → 知识库 → 工作流 → 插件 → 试跑
3. **100-112 分钟**：按环节截图（创建应用/知识库/工作流/试跑结果 4-6 张），回填文档
4. **112-115 分钟**：导出 PDF/Word，检查图片清晰度

## 阶段五：交付检查（115-120 分钟）

- [ ] 三份交付物齐全：A（文档+截图）、B（Markdown 提示词）、C（代码+截图）
- [ ] 命名规范、路径清晰、无乱码
- [ ] 文档中无【】占位残留（全部替换完成）
- [ ] 截图清晰可读、与文字一一对应
- [ ] 代码可在现场机器复现运行（至少 demo 可跑）

## 通用得分技巧

- **B、C 共用一套知识与提示词**：让三题内容互相呼应，评审会认为体系完整
- **截图比文字更值钱**：每一处功能声明都配一张真实运行截图
- **文档结构清晰**：用小标题、表格、编号，评审快速看到"痛点→方案→效果"逻辑
- **异常机制是 C 题差异化项**：展示"无知识兜底、模型失败降级"比只展示成功路径更完整
- **多模态是加分项**：C 题务必展示 1 张图片识别截图
